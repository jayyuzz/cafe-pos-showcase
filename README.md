# Cafe POS

**Live:** https://cafe.mve.my.id (login required)

Point-of-sale and back-office system for a cafe & restaurant. This repository is a showcase only. The source is private.

## Features
- POS with cashier shifts, cash reconciliation, receipts and thermal printer API
- Kitchen display (KDS), dine-in via table QR, takeaway and delivery with driver checklist
- Raw-material inventory, recipe-based stock deduction, automatic COGS
- Reservations, waste tracking, WhatsApp order notifications
- Sales reports and BI dashboards, role-based access and user management

## Stack
Next.js · TypeScript · Supabase (PostgreSQL, Auth) · Recharts · Tailwind CSS
